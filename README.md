# Subadevan C — portfolio

Live at **https://subadevan.tech**

Next.js 16 · TypeScript · Tailwind CSS 4 · Motion. Fully static.

```bash
npm install
npm run dev            # http://localhost:3000
npm run build && npm start
npm run data:ctftime   # refresh the Flaggers United snapshot from the official CTFtime API
```

## Editing content

All content lives in `data/` — no component changes needed:

| File | What |
|---|---|
| `profile.ts` | name, intro, contact, socials, certifications |
| `research.ts` | case studies (Vercel featured), disclosure ledger, internship |
| `competitions.ts` | every result; `place` sets the order and the win count (top 3) |
| `timeline.ts` | milestones (verified dates only) |
| `community.ts` | Flaggers United, CyberNexus roles, events organized/attended |
| `certifications.ts` | everything on `/certifications` |
| `photos.ts` | event and evidence photos (files live in `public/achievements/`) |
| `roster.json` | public CTFtime roster snapshot (edit by hand) |
| `ctftime.json` | generated by `npm run data:ctftime` |

Anything left undefined renders as a visible `[ADD: …]` placeholder.

## Deploying

On Vercel the site URL is detected automatically; set `NEXT_PUBLIC_SITE_URL` only for a custom domain.
Security headers (CSP, HSTS, etc.) are set in `next.config.ts`; they apply on Vercel or `next start`, not on static-only hosts like GitHub Pages.
